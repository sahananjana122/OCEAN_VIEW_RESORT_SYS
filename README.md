# 🏨 Ocean View Resort - Reservation Management System

A **web-based hotel reservation management system** developed using **Java EE, Servlets, JSP, and MySQL**.  
The system allows resort staff to efficiently manage reservations, guest information, billing, and operational status in real time.

---

## 📋 Features

- 🔐 **User Authentication**
  - Role-based login (Admin / Staff)

- 📅 **Reservation Management**
  - Create reservations
  - View reservation details
  - Update reservation information
  - Delete reservations

- 🔎 **Search Functionality**
  - Search reservations by guest name

- 🧾 **Billing System**
  - Automated bill calculation
  - Invoice generation

- 📊 **Dashboard**
  - Real-time reservation statistics
  - Overview of resort activity

- 🔄 **Reservation Status Management**
  - Confirmed → Checked-In → Checked-Out workflow

---

## 🛠️ Tech Stack

| Layer | Technology |
|------|------------|
| Backend | Java 8, Servlets 4.0, JSP 2.3 |
| Database | MySQL 8.0 |
| Build Tool | Maven 3.6+ |
| Server | Apache Tomcat 9.x |
| Testing | JUnit 4.13.2 |
